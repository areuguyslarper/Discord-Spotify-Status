# Discord-Spotify-Status
I created a Python script that sets your Discord status to the song you're listening to on Spotify; it only works on Windows and Linux—it hasn't been tested on macOS, but you can test it yourself if you'd like.
A small project that displays the song I'm listening to on Spotify in my Discord status.

## Features

-  Displays the current song from Spotify
-  Uses Discord Rich Presence
-  Updates the status when the song changes
